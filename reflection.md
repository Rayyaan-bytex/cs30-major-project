# Major Project Reflection

## What advice would I give to myself if I was to start a project like this again?
- Plan the structure of the code first (what functions, variables, and classes I will need) before writing everything in one place
- Don't underestimate how long small features take as some features were harder than they looked
- Comment the code while writing it, not after, so it's easier to understand later and save time
